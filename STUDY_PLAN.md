## 4. План сегодняшнего занятия

### Блок A. Алгоритмические задачи

Начни с одной практической задачи уровня junior+/middle на C#.

Приоритетные темы:
- строки и массивы;
- Dictionary и HashSet;
- поиск дубликатов и частот элементов;
- Stack и Queue;
- LINQ;
- временная и пространственная сложность O(n), O(n log n), O(n²);
- простые задачи на поиск и рекурсию.

Предпочтительны задачи, похожие на реальные тестовые задания работодателей, а не сложные соревновательные алгоритмы.

Для каждой задачи:
- дай условие и примеры входных и выходных данных;
- попроси меня описать идею;
- затем попроси написать решение на C#;
- проверь корректность, граничные случаи и сложность;
- после разбора предложи следующую задачу немного сложнее или на слабую тему.

Не переходи к следующей задаче, пока мы не разобрали текущую.

### Блок B. C# — теория уровня Middle

Последовательно проверь следующие темы:

1. `var`, `object`, `dynamic`: различия, статическая типизация, время проверки типов, boxing/unboxing.
2. `ref`, `out`, `in`: семантика и практические сценарии.
3. Value types и reference types, стек и куча без упрощённых мифов.
4. `record`, `class`, `struct`, неизменяемость.
5. Generics, ограничения generic-параметров, variance (`in`/`out`).
6. Делегаты, события, лямбда-выражения.
7. LINQ: deferred execution, `IEnumerable<T>` и `IQueryable<T>`, `Select`, `Where`, `Any`, `First` и `FirstOrDefault`.
8. Исключения, `IDisposable`, `using`, финализаторы.
9. `async`/`await`, `Task`, `Task<T>`, `CancellationToken`, TAP.
10. Разница между асинхронностью и многопоточностью.
11. `lock`, `Monitor`, `SemaphoreSlim`, `Interlocked`, гонки данных и deadlock.
12. Коллекции `Dictionary`, `HashSet`, `List`, `ConcurrentDictionary` и их применение.

Не пытайся охватить всё поверхностно: сначала выясни мой уровень, затем выбирай приоритеты.

## Прогресс на 20.10.2026

**Пройдено — не повторять без конкретной причины:**
- Алгоритм: массивы, `Dictionary`, частоты элементов, первый уникальный элемент, сложность O(n).
- C#: `var` / `object` / `dynamic`, boxing, `ref` / `out` / `in`.
- `class` / `struct` / `record`, `with`, value types и reference types.
- LINQ: deferred execution, `IEnumerable<T>` и `IQueryable<T>`.
- Async/TAP: `async` / `await`, асинхронный I/O, `Task.Run`, `Task.WhenAll`, ошибки асинхронных операций.
- `CancellationToken`: передача вниз по цепочке вызовов для отмены ненужной работы.

Не повторять перечисленные темы по кругу. Возвращаться к ним только при обнаружении конкретного пробела.
